# Task 1
# Student Grade Tracker
The Student Grade Tracker is a Java-based console application developed to manage and analyze student academic scores. The project allows users to enter student names and grades, store the data using an ArrayList, and generate a summary report showing the average, highest, and lowest scores.

The main purpose of this project is to demonstrate the use of:

-Object-Oriented Programming (OOP)
-ArrayList data structure
-Loops and conditional statements
-User input handling in Java
## Features
Add student names and marks
Store records dynamically using ArrayList
Calculate:
-Average score
-Highest score
-Lowest score
-Display all student details in a formatted report
## Technologies Used
-Java
-ArrayList
-Scanner class

# Task 2
# Stock Trading Platform

A console-based stock trading simulation system developed using Java and Object-Oriented Programming concepts. This project allows users to view market data, buy and sell stocks, track portfolio performance, maintain transaction history, and store user data using file handling.

## Features
- Add money to account
- View stock market data
- Buy and sell stocks
- Portfolio tracking
- Profit/Loss calculation
- Transaction history
- File handling for saving user data

## Technologies Used
- Java
- OOP Concepts
- Collection Framework
- File Handling
